# 🚀 BERT-Powered Intent Chatbot & Flask API

An intelligent end-to-end chatbot built using **BERT (Transformers)**, **PyTorch**, and **Flask**. It classifies user intents with high accuracy and serves responses in real-time through a web interface.

## 🛠️ Tech Stack
* Python, PyTorch, Hugging Face Transformers (BERT)
* Flask (Backend API)
* HTML/CSS & JavaScript (Frontend)
